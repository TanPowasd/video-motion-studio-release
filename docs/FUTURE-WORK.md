# 后续功能与优先级

按质量、自由度、外部 agent 使用优先排序。这是待实现/待深化清单，不是已完成能力或日历承诺。已有关键帧、动作模板、基础检查/修复、时间效果、解析粒子和网格/局部采样变形不重复作为新功能。

UI增量已提供八类可视化创作工具，包含节点画布、动画层、表达式/布局/路径、3D/粒子、分镜/混音及检查/性能。下面涉及“节点画布、动画层面板”等条目已有首版，剩余是更高级操作/完整专业工作流；详细能力边界见VISUAL-WORKSTATION.md。MCP支持按字段交付和短元数据，但不将本轮称作全部协议永远无需改进。
