# Vmotion 0.1.2 · Studio、插件包、图片与字形

开源预览版，整合新版 Studio 和这一批创作功能。

- **Studio 界面**：剪辑、动效、特效、音乐、图片、文字六种工作模式，支持 Ctrl+1…6 切换。改进时间轴拖动、缩放与吸附，加入命令面板、快捷键说明和操作提示。
- **共享工程**：人通过 UI 编辑，外部 AI 通过文件、CLI 或 MCP 操作同一工程。变更记录显示来源和目标对象，便于跟踪同步修改；程序不调用 AI 模型。
- **插件包**：支持 `.vmplugin` 打包、安装和升级，校验依赖、文件哈希与包路径；新版插件管理器提供健康诊断和修复入口。
- **静态图片**：支持画板、尺寸预设、模板、对齐吸附和多尺寸变体，导出 PNG、JPEG、WebP。
- **字形创作**：支持自定义字形集、中文部件组合（IDS）和字体回退，接入文字与字幕渲染。
- **外部工具**：以上能力同时接入 CLI/MCP，默认 MCP 保持 10 个紧凑入口，按需发现 147 项能力。

Windows 10/11 x64：下载 `Vmotion-Windows-x64-Portable.zip`，完整解压后运行 `Vmotion.exe`。无需单独安装 Node.js 或 FFmpeg。

发布前验证：类型检查与构建通过；106 个测试文件、564 项测试通过。便携版的真实 stdio MCP、插件包、图片导出、字形、Studio 桌面流程、共享文件修改与撤销、音乐/VST3，以及复制到中文和空格路径后的导出均通过验收。

源码采用 Apache-2.0，第三方依赖保留各自许可。当前发布为预览版；AU/macOS 尚未实机验收。
