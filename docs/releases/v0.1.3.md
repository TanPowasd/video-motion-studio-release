# Vmotion 0.1.3 · 主题切换与画布交互

开源预览版，同步这一批界面和交互更新。

- **界面主题**：支持跟随系统、暗色、亮色，首页、Studio 菜单和工程设置均可切换，支持 `Ctrl+Alt+D`。桌面偏好保存在本机，跨工程与重启保留；主题不改变工程内容或视频画面。
- **选框与缩放**：选中图层的角点手柄优先响应，避免被重叠图层抢占；拖动角点缩放，保持对角位置，支持 `Shift` 等比缩放、撤销和 `Escape` 取消。
- **时间轴**：修正播放指针顶部手柄的居中位置。
- **发布验收**：新增真实桌面主题持久化、画面一致性、原生鼠标缩放、取消及撤销检查。

Windows 10/11 x64：完整解压 `Vmotion-Windows-x64-Portable.zip` 后运行 `Vmotion.exe`。无需单独安装 Node.js 或 FFmpeg。

人通过 UI 编辑，外部 AI 通过文件、CLI 或 MCP 操作同一工程；程序不调用 AI 模型。

发布前验证：类型检查、构建、107 个测试文件和 579 项测试通过。便携版真实 MCP、主题切换与重启恢复、画布原生拖动缩放／撤销／取消、共享文件编辑、音乐／VST3、图片、字形和插件包均通过验收；复制到中文和空格路径后可正常导出。

源码采用 Apache-2.0，第三方依赖保留各自许可。当前发布为预览版；AU/macOS 尚未实机验收。
