# Isolated native audio host

The SDK and JSON header are fetched into ignored artifacts using pinned versions by `scripts/build-audio.ps1`. The host and test fixture use the current MIT Steinberg VST3 SDK; dependencies are not checked into this repository. The portable distribution retains SDK/json notices and provenance. The static Windows C runtime keeps the host portable.

`main.cpp` implements bounded framed JSON + float32 stereo PCM over stdio with a command reader and platform UI main loop. `vst-host.cpp` manages component/controller lifecycle, parameters, state, MIDI, process context and the Windows native editor. `au-host.mm` implements the macOS Audio Unit backend; it is currently unverified on macOS hardware. `fixture.cpp` is our own test instrument/effect/editor, not a distributed third-party plugin.

The Windows SDK module loader is compiled with a local UTF-8 path correction generated by CMake. The pinned checkout is preserved. All source remains available for review; scan/process code does not provide an AI model integration.
